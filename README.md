### Features

1. **Local AI Model**

   * Powered by Google's **Gemma 3 1B IT QAT Q4_0** local AI model.
   * Runs locally using **GPU/TPU acceleration** for fast and private AI interactions.

2. **Server-Based Messaging System**

   * Dedicated common club for each college.
   * Enables users to communicate and interact with other students.
   * Supports centralized, server-based messaging.

3. **Server-Synchronized Tracker**

   * Synchronizes tracker data with the server.
   * Keeps user progress and activity consistent across devices.

4. **Advanced PDF Canvas System**

   * Interactive PDF viewing and canvas-based interaction.
   * Designed for studying, annotation, and document interaction.

5. **Mail Notice API System**

   * Directly delivers important notices to users through email.
   * Provides automated communication through a dedicated mail API.

6. **Sponsor Banner System**

   * Allows users to sponsor celebrations, events, and organizational activities.
   * Sponsored banners can be displayed to the BEU CLUB community.

7. **Calendar System**

   * Allows users to add and manage events for specific dates.
   * Helps students organize academic and personal activities.

8. **BEU Utilities**

   * **Notices:** Directly fetched from the BEU backend server.
   * **Results:** Access results directly from the BEU backend server.
   * **Holidays:** Provides an organized holiday calendar.
   * **PYQs:** Previous Year Questions with server-based completion tracking and integration with the local AI model.
   * **Syllabus:** Provides syllabus information with server-based completion tracking and local AI integration.

9. **Comments & Community Interaction**

   * Users can leave comments and share feedback.
   * Enables community interaction around relevant content and activities.


### Installation

```bash
# Clone the repository
git clone https://github.com/Tejas-India-Hackathon-2026/Team-The-Matrix.git
cd Team-The-Matrix

# Install dependencies
npm install

# Run the project
npm start
```
